# Datia brand (working name)

Placeholder identity until the final company name is chosen.

| File | Use |
| --- | --- |
| `datia-mark.svg` | App icon, favicon, avatar. Works from 16 px up. |
| `datia-logo.svg` | Mark + wordmark for the portal header, documents and decks. |

- **Idea:** a lowercase *d* drawn as a data ring and a rising bar (BI), with a small spark (AI).
- **Colors:** larimar `#1f7f97` (the Dominican stone, already the portal accent), spark `#9fe0ee`, ink `#142a30`. On dark backgrounds use ink `#e3eef0` and larimar `#5cc0d8`.
- **Type:** Familjen Grotesk 700 for the wordmark and headings; Public Sans for text; IBM Plex Mono for numbers and codes (all free on Google Fonts).
- Before printing or registering at ONAPI, have a designer convert the wordmark to outlines and check the name is free.
