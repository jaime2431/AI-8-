# Data Bridge Analytics brand

Final company name, registered in the Dominican Republic (October 2026). Replaces the working name "Datia".

| File | Use |
| --- | --- |
| `databridge-mark.svg` | App icon, favicon, avatar. Works from 16 px up. |
| `databridge-logo.svg` | Mark + wordmark for the portal header, documents and decks. |

- **Idea:** a bridge between two data pillars, the client's past (short) and future (tall), with a data point crossing it. Data Bridge connects what a company already has to the decisions it needs.
- **Colors:** larimar `#1f7f97` (the Dominican stone, also the portal accent), data point `#9fe0ee`, ink `#142a30`. On dark backgrounds use ink `#e3eef0` and larimar `#5cc0d8`.
- **Type:** Familjen Grotesk 700 for "Data Bridge", 600 spaced capitals for "ANALYTICS"; Public Sans for text; IBM Plex Mono for numbers and codes (all free on Google Fonts).
- Before printing, have a designer convert the wordmark to outlines.
- Code names (`datia-backbone`, the `DATIA__` environment variables) stay as they are: renaming them would break configured servers for no visible gain.
